# Changelog

## 0.1.0

Initial experimental source release for the pinned Windows desktop build.

- Native permanent-delete menu and confirmation, including stop-and-delete for running conversations.
- Server-side deletion planning, scope revalidation, exclusive locking, journal recovery and completion events.
- Cleanup for conversation generations, nested subagents, indexes, projections, exclusive output and unshared attachments.
- Independent forks and project files preserved; client cache and delayed-write cleanup.
- Local installation, status and uninstall commands, with program/configuration backups.
- Portable installation settings, Chinese/English documentation and isolated test tooling.

Supports DeepSeek Harness Desktop `0.2.1-rc.5` on Windows. It is not a standalone marketplace installation.
